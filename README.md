# My Mini Workout

A small, responsive workout generator made with plain HTML, CSS, and JavaScript. It uses sample exercises and does not need a login, database, paid service, package installation, or build step.

## Run it

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Choose Beginner, Intermediate, or Advanced and a 10, 20, or 30-minute workout.
4. Select **Generate Workout**. Tick the boxes as you finish exercises.

## Open it in Codex

1. Open the `my-mini-workout` repository in Codex.
2. Ask Codex for a specific change, for example: “Add a rest timer to each exercise” or “Add a print workout button.”
3. Review the changes and test `index.html` in your browser.

## Project files

- `index.html` — complete app, including styles and JavaScript.
- `README.md` — these setup notes.

All workout plans are sample suggestions. Choose movements and effort that feel comfortable for you.
